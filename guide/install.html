Install

Add the theme, with smalldocs or with Quarto.

The theme is one folder, _extensions/tufte/. It holds a stylesheet for each mode, the ET Book fonts, and the same rules written for Quarto.

With smalldocs

smalldocs add rahuldave/smalldocs-tufte

This copies the folder into _extensions/tufte/ and notes where it came from. Then name the theme in _smalldocs.yml:

theme: tufte

In a _quarto.yml, the line goes under smalldocs:, which Quarto ignores:

smalldocs:
  theme: tufte
Keep it up to date

smalldocs themes lists the themes of a project, with the command that fetches each one again.

With Quarto

quarto add rahuldave/smalldocs-tufte
format:
  tufte-html:
    toc: true

On any Bootstrap page

Each stylesheet is a whole Bootstrap 5.3 with the Tufte rules after it, as a Bootswatch theme is. So a page that links to tufte.css in place of bootstrap.min.css gets the theme. Keep the et-book folder next to it.
